# Project IT — Machine Learning & Computer Vision



<a id="العربية"></a>
## العربية

يضم هذا المستودع ثلاث تجارب تعليمية في تعلم الآلة والرؤية الحاسوبية، موثقة في دفاتر Jupyter ويمكن فتحها باستخدام Jupyter Notebook أو Google Colab.

### المشاريع

#### 1. التعرّف على النصوص التايلاندية — `ThaiCRNN_Colab.ipynb`

دفتر لتجربة بناء نموذج OCR للتعرّف على النصوص التايلاندية داخل الصور باستخدام PyTorch ومعمارية CRNN. تجمع المعمارية بين CNN لاستخراج الخصائص البصرية، وBiLSTM لمعالجة تسلسل الحروف، وCTC لفك التنبؤ. يتضمن الدفتر إعداد بيئة Colab، وتجهيز بيانات الصور والتسميات، وفحص أبعاد النموذج، والتدريب والاستدلال، وحساب Character Error Rate (CER).

#### 2. تصنيف المعاملات المالية — `SVM.ipynb`

دفتر لتحليل بيانات معاملات مالية وتجهيز الميزات، ثم تدريب ومقارنة نموذجي SVM وRandom Forest باستخدام مقاييس التصنيف ومصفوفة الالتباس. بحسب النتائج المحفوظة في الدفتر، تفوّق Random Forest على SVM الخطي في التجربة المعروضة. تعتمد النتائج على البيانات وتقسيم التدريب والاختبار المستخدمين، ولا تمثل ضمانًا للأداء على بيانات أخرى.

#### 3. توليد صور الأشكال من زوايا مختلفة — `run_nerf.ipynb`

تجربة باستخدام PyTorch لتوليد بيانات اصطناعية لأشكال هندسية، ثم تدريب نموذج بأسلوب GAN على توليد صورة للشكل من زاوية كاميرا مختلفة اعتمادًا على صورة ومدخلات زوايا. تشمل الأشكال المذكورة المكعب والكرة والمخروط والهرم والطارة. رغم اسم الملف، يصف الدفتر تجربة لتوليد/تحويل الصور المشروط بمعلومات الكاميرا، ولا ينبغي اعتباره تطبيق NeRF تقليديًا دون تحقق إضافي.

### التقنيات والأدوات

- Python وJupyter Notebook وGoogle Colab
- PyTorch وscikit-learn
- CRNN وCNN وBiLSTM وCTC وSVM وRandom Forest وGAN

### التشغيل

افتح ملف `.ipynb` المطلوب في Jupyter Notebook أو Google Colab، ثم راجع خلايا الدفتر لمعرفة المكتبات والبيانات المطلوبة. قد تتطلب بعض خطوات التدريب وحدة GPU أو ملفات بيانات خارج المستودع.

### ملاحظات

- يحتوي المستودع على تجارب منفصلة، وليس تطبيقًا واحدًا متكاملًا.
- النتائج المحفوظة في الدفاتر تجريبية؛ أعد تقييم النماذج على مجموعة اختبار مستقلة قبل الاستشهاد بأرقام الأداء.
- قد لا يتضمن المستودع جميع مجموعات البيانات أو ملفات التدريب اللازمة لإعادة تشغيل التجارب كاملةً.
